Essa aplicação foi desenvolvida como parte da Atividade Pratica Orientada (APO) da diciplina de Fundamentos de Progração para Internet da UNIPAR EAD.

A aplicação RotaCerta é uma aplicação WEB desenvolvida utilizando PHP, HTML, CSS, JavaScript, Bootstrap e MySQL, com o objetivo de facilitar o gerenciamento de processos logísticos.

Permite o cadastro de produtos, endereços de origem e destino, transportadores e fretes.

Possibilita a criação de frete vinculando diferentes produtos a um mesmo transportador, Também oferece funcionalidades de edição de registros e consulta de informações por data.


Tecnologias utilizadas:
PHP
HTML
CSS
JavaScript
Bootstrap
MySQL
